ABOUT PIXELFIX PRO

Everyday image and PDF tools, in one place

PixelFix Pro helps you resize photos, compress images, convert between JPG, PNG and WEBP, crop or rotate pictures, inspect image details, render PDF pages as PNG, and combine images into a PDF. Select a tool above to open its dedicated page.

Are these tools free?

Yes. This version has no account or payment step. Third-party libraries used for PDF features require an internet connection.

Are my files uploaded?

Image editing happens in your browser. This static site does not include an upload API. PDF features load open-source libraries from a CDN.
